## 2. LA TRINIDAD DE HERRAMIENTAS

### 2.1 Principio de Diseño

Cada herramienta tiene un rol **exclusivo** y un flujo claro entre ellas:

| Fase | Herramienta | Qué se hace | Ejemplo |
|------|-------------|-------------|---------|
| **Capturar** | Obsidian (Inbox) | Notas fugaces, ideas, links | `00_INBOX_TEMPORAL` → `PLANTILLA_Apunte` |
| **Planificar** | Notion | Proyectos, entregables, calendarios | `PIPELINE DE ENTREGABLES`, `INVASIÓN SEMANAL` |
| **Pensar** | Obsidian | Destilar, conectar, estudiar | Zettelkasten + Active Recall 3 formas + SR |
| **Ejecutar** | Todoist | Tareas de hoy, acciones inmediatas | `@hoy`, `@semana`, `@urgente` |
| **Revisar** | Ambos | Daily review, weekly review | `Ctrl+P` Periodic Notes + `HOME` Notion |

### 2.2 Flujo Diario Recomendado

```
🌅 MAÑANA (10 min)
├── 1. Obsidian → Ctrl+P → "Periodic Notes: Open today" → Daily V2
├── 2. Responde Daily Questions (4) + Today's Focus Top 3
├── 3. Revisa Todoist @hoy (ya sincronizado con Notion)
├── 4. Abre Notion → THE EGG-NETWORK → HOME
│   ├── MONITOR INTEGRIDAD (energía ≥ 0.7?)
│   ├── ORDEN DE BATALLA (prioridades)
│   └── INVASIÓN SEMANAL (semana en curso)

🌞 MEDIODÍA (2-5 min)
├── 1. Marca hábitos en MONITOR (Hecho Hoy ✓)
├── 2. Captura fugaz en Obsidian Inbox (si surge algo)

🌙 NOCHE (10-15 min)
├── 1. Cierra Daily V2 → X del día (3 condiciones)
├── 2. Dataview: Notas creadas/modificadas hoy → destila 1
├── 3. Micro-auditoría (4 pasos)
├── 4. Sync: Notion (entregables) → Todoist (mañana)
```

### 2.3 Qué NO se duplica

- **No** pongas el mismo apunte en Notion y Obsidian → Obsidian piensa, Notion gestiona.
- **No** uses Notion para notas atómicas → eso es de Obsidian.
- **No** uses Todoist para proyectos → eso es de Notion.
- **No** uses Obsidian para calendarios → eso es de Notion Calendar.
- **No** uses Notion para ejecución diaria → eso es de Todoist.
