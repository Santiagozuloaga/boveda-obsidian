# ⚡ GUÍA RÁPIDA E-100 (2 min)
**Lo único que necesitas para operar el sistema.**

## Mañana
1. `Ctrl+P` → *Daily notes: Open today's daily note* → escribe tu Top 3 en Foco.
2. Mira `HOY` (tablero) y Todoist `@hoy`. Trabaja.

## Capturar (cuando aparezca una idea)
1. `Ctrl+P` → *Templater: Insert template* → `PLANTILLA_Apunte` en `00_INBOX_TEMPORAL`.
2. Escribe 3 líneas + 1 `[[link]]`. Cierra. **No decidas carpeta ni tags.**

## Estudiar (clase, libro, alemán, código)
1. Crea la nota en su carpeta → la plantilla correcta se aplica sola (Daily, Apunte, Vocabulario, Fuente, Libro).
2. Si no se aplicó nada: `Ctrl+P` → *Templater: Insert template* → elige (Clase, Reunión, Proyecto, Ensayo, MOC...).
3. Regla: reescribe con tus palabras + 2–3 links. Marca `#flashcards/...` lo que va a repaso.

## Noche (5 min)
1. Daily → Reflexión (gratitud + lección) → Cierre E-100 (micro + MCs + energía + X).
2. Listo. Nada más es obligatorio.

## Domingo (15 min, revisión semanal)
1. Vacía `00_INBOX_TEMPORAL`: cada nota → su MOC o se borra.
2. Crea la semanal: `Ctrl+P` → *Templater: Create new note from template* → `PLANTILLA_Revision_Semanal` → nombre `2026-W39` en `01_DIARIO_DE_GUERRA/04_Revisiones`.
3. Score X/7 + 1 victoria + 1 lección + 3 prioridades.

## Recuperar algo viejo
`Ctrl+Shift+F` (Omnisearch) → concepto → o abre su MOC → sigue links. Si no lo encuentras en 30 seg, el problema es falta de links, no de carpetas.

## Fronteras (no romper)
- ¿Es gestión/fechas/estructura? → **Notion**.
- ¿Es acción de mañana con hora? → **Todoist**.
- ¿Es pensar/aprender/conectar? → **aquí**.
