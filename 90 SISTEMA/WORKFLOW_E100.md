# 🔄 WORKFLOW E-100 — Capturar → Expresar
**El recorrido completo de una idea hasta conocimiento reutilizable.**

```
CAPTURA (5 seg, cero fricción)
  idea → 00_INBOX_TEMPORAL (Apunte auto) → cerrar
                    ↓ (revisión semanal 15 min)
PROCESAMIENTO (¿sirve en 30 días para examen/proyecto/código?)
  SÍ → destilar: palabras propias + 4 props + 2–3 [[ ]] → mover a su MOC
  NO → borrar (coleccionar ≠ aprender)
                    ↓
CONEXIÓN (al escribir, nunca en sesiones de "linkear")
  cada nota nueva enlaza 2–3 notas/MOCs previos
  MOC = índice curado a mano, no lista auto
                    ↓
ESTUDIO (Active Recall + Spaced Repetition)
  Toggle/Gallery/Media en la nota → `#flashcards/...` → SR o Anki 10 min/día
  Alemán: VERBO → PREPOSICIÓN → CASO → EJEMPLO → VOCAB → GRAMÁTICA → TEXTO → SR
  Universidad: MATERIA → CLASE → CONCEPTO → FUENTE → CONEXIONES → PROYECTO → ENSAYO
                    ↓
EXPRESIÓN (el sistema existe para esto)
  examen · código que corre · ensayo/tesis · clase explicada sin mirar
                    ↓
RECUPERACIÓN (Omnisearch → MOC → links; <30 seg o falta link, no carpeta)
```

## Ritual semanal (único mantenimiento obligatorio)
Domingo 15 min: vaciar Inbox + semanal (score, victoria, lección, prioridades). Sin esto, el sistema decae en ~6 meses [CONSENSO comunidad].

## Antipatrones (no hacer)
- Dashboard con 20 widgets que nadie abre → HOME es mapa, Control Panel es optativo.
- 200 tags o YAML de 15 campos → 8 tags, 4 props.
- Guardar todo "por si acaso" → filtro 30 días.
- Automatizar antes de sufrir la fricción 1 semana → nada entra sin fricción probada.
