# Passiv (Heute 11.08.2026)

## 📌 Kern
Man benutzt Passiv für Prozesse. Subjekt unwichtig/unbekannt. Hilfsverb: **werden**.

## 🧠 Formel
**Subjekt + werden + (TeKaMoLo) + von+Dat + Partizip II**
- Präsens: *Das Brot **wird** gebacken.*
- Präteritum: *Das Auto **wurde** 1830 erfunden.*

## 🔗 Conexiones
- werden → [[Konjunktiv II]] (mismo verbo, otro modo).
- Frase: Passiv se conecta con [[_MOC_ALEMAN]] porque describe procesos sin actor.

## 🃏 Repaso
```
Das Brot wird gebacken :: Aktiv? — Der Bäcker bäckt das Brot.
==wird== / ==wurde== → Präsens / Präteritum de werden en Passiv
```
