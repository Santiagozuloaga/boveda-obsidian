# 💻 BUCLES FOR / WHILE

**Concepto atómico:** Repetir una acción hasta cumplir una condición.

---

## 📝 PYTHON
```python
# For: iterar sobre una secuencia
for i in range(5):
    print(i)

# While: repetir mientras condición sea verdadera
contador = 0
while contador < 5:
    contador += 1
```

## 🧠 CUÁNDO USAR
- **For:** sabes cuántas veces repetir (recorrer [[Estructuras de Datos]])
- **While:** no sabes cuántas veces, depende de condición

## 🔗 CONEXIONES

---

**Explicación propia:** Un `for` es como repasar la lista de tareas del día. Un `while` es como "sigue estudiando hasta que domines el tema".
