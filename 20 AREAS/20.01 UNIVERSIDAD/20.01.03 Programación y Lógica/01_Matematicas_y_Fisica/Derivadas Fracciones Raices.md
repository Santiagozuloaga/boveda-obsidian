# 📐 Derivadas SAGE-X: fracciones y raíces (disfraz)

## 📌 Idea central
Regla de potencia solo come x arriba con exponente normal. Disfraza primero: baja denominadores (signo −), raíces → exponentes fraccionarios.

## 🧠 Recetas
- `5/(3x²) - 3/x² + 1/x` → `(5/3)x⁻² − 3x⁻² + x⁻¹` → agrupa → deriva → limpia: `8/(3x³) − 1/x²`.
- Raíz: adentro arriba, índice abajo (`³√(x²) = x²/³`).
- `2x → 2` · constante sola → `0`.

## 🔗 Conexiones
- Frase: el disfraz se conecta con [[Cálculo Diferencial]] porque prepara la potencia.

## 🃏 Repaso
```
³√(x²) como exponente :: x²/³ (adentro arriba, índice abajo)
f(x) = 1/x → f'(x) :: −1/x²
```
