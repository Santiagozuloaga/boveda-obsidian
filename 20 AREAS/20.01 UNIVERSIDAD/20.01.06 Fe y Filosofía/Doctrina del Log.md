# Doctrina del Log v2 — Radar de distracciones

El sistema anterior era autocomplaciente: registraba heridas y no servía. Nuevo protocolo:

1. **Objeto:** solo distracciones y fugas (digitales, mentales, de entorno). Nada de historial emocional.
2. **Formato por fila:** Distracción (1 línea) → Vector/fuente → Contramedida concreta → Blindaje ✓ cuando se aplicó.
3. **Puerta estoica:** ¿depende de mí? NO → silencio y descarte. SÍ → contramedida con fecha.
4. **Regla de oro:** fila sin contramedida = fila que no debió existir. Prohibida la lástima.

El Log no se relee para sentir; se consulta para blindar.
